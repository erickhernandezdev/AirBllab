Estado del Sistema

Funcionalidades Implementadas: Autenticación, Panel Admin, Gestión de Usuarios, Sistema de Aprobación

Seguridad: 2FA Configurado, Protección contra Fuerza Bruta, Headers de Seguridad

Estado: Sistema completamente operativo y listo para evaluación

Seguridad Avanzada

Autenticación de dos factores (2FA) y protección contra ataques de fuerza bruta implementados con django-axes.

Gestión de Propiedades

Sistema completo para administrar alojamientos, habitaciones y experiencias únicas con aprobación administrativa.

Sistema de Roles

Diferentes permisos para administradores y usuarios regulares con modelo de usuario personalizado.

Aprobación de Contenido

Los administradores revisan y aprueban propiedades antes de que estén disponibles para reservas.

Panel Administrativo

Interfaz personalizada para gestión de usuarios, aprobaciones y monitoreo del sistema.

Auditoría Completa

Registro de todas las acciones administrativas y sistema de logging para auditoría de seguridad.
